# pensieve

Pensieve — Claude의 기억 그릇. 메모리 기능 전체를 여는 **단일 진입점**입니다.

`/pensieve`가 호출되면 아래 메뉴를 **그대로** 사용자에게 보여주세요. 그런 다음 사용자가 **번호 또는 자연어**로 말하면, 맨 아래 매핑표를 보고 해당 동작을 실행하세요.

## 보여줄 메뉴

```
  🪄  PENSIEVE — 기억의 그릇
  대화에서 쌓인 기억을 보고 · 찾고 · 정리합니다. 번호나 자연어로 말하세요.
  ──────────────────────────────────────────────

  ⭐ 자주 쓰는 것
     1 · 보기         지금까지 저장된 기억을 한눈에 요약
     2 · 검색         키워드로 찾기 (대화 기록까지 검색 가능)
     3 · 저장         지금 이 내용을 기억으로 남기기

  🧹 정리
     4 · 통계         몇 개 · 어느 프로젝트에 저장됐는지
     5 · 중복 정리    비슷한 기억을 하나로 합치기
     6 · 노이즈 청소  잘못 섞인 쓰레기 기억 제거
     7 · 삭제         특정 기억을 콕 집어 지우기

  ⚙️ 고급
     8 · 수정         기존 기억을 새 내용으로 교체
     9 · 프로젝트 전환  기억을 다른 프로젝트 칸으로 전환
    10 · 보관 모드     기억 주입 방식 변경 (full/compact/none)
    11 · 오래된 정리   N일 지난 기억 자동 정리
    12 · 인덱스 재구축  검색이 실제 파일과 어긋날 때 새로고침
    13 · 컨텍스트 확인  Claude에게 주입되는 기억 미리보기
    14 · 프로필 설정   선호도·환경 인터뷰 (첫 설정용)

  ──────────────────────────────────────────────
  💬 예: "2번"  ·  "winget 찾아줘"  ·  "이거 기억해둬"  ·  "정리해줘"
```

## 번호·의도 → 실행 매핑

`node ~/.claude/hermes-memory/memory-cli.js <명령>` 으로 실행합니다 (8·13·14는 별도 표기).

| # | 의도 키워드 | 동작 |
|---|---|---|
| 1 | 보기·뭐 기억해·요약 | `~/.claude/memory/{USER,MEMORY,FAILURES,SKILLS,PROJECTS}.md` 읽고 한국어 요약 |
| 2 | 검색·찾아줘 | `search "키워드"` (대화 기록 포함은 `--sessions`) |
| 3 | 저장·기억해 | `add <대상.md> "내용" [--scope global|project] [--category ...]` |
| 4 | 통계·몇 개 | `stats` |
| 5 | 중복 정리·합쳐줘 | `consolidate` (짧은 중복까지는 `--llm`) |
| 6 | 노이즈 청소 | `clean-noise` (`--dry-run`으로 미리보기) |
| 7 | 삭제·지워줘 | `remove <대상.md> "검색어"` |
| 8 | 수정·바꿔줘 | `replace <대상.md> "검색어" "새 내용"` |
| 9 | 프로젝트 전환 | `switch-project <이름>` (`clear`로 해제) |
| 10 | 보관 모드 | `mode show|full|compact|none|...` |
| 11 | 오래된 정리 | `prune [--older-than DAYS] [--dry-run]` |
| 12 | 인덱스 재구축 | `sync-markdown` |
| 13 | 컨텍스트 확인 | `preview-context [--json]` |
| 14 | 프로필 설정 | `/memory-interview` 스킬 절차 진행 |

규칙: 결과는 한국어로 요약하고, 비밀(시크릿)은 절대 노출하지 마세요. 의도가 모호하면 한 번 더 짧게 되물으세요.
