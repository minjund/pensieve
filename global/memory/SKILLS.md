# Global Skills

Reusable procedures.

## Use Global Memory in Claude Code

When starting work:

1. Check `~/.claude/CLAUDE.md`.
2. If prior context may matter, read files in `~/.claude/memory/`.
3. Use project-local instructions first for project-specific decisions.
4. Apply global memory only where relevant.
5. Do not treat memory as absolute truth.

## Prepare a Non-Developer Handoff

1. Avoid developer-only artifacts such as DB files, `node_modules`, package caches, and internal extension folders.
2. Convert important knowledge into Markdown.
3. Include a short `README_먼저읽기.md`.
4. Include exact copy/install steps.
5. Include a warning not to store secrets.
